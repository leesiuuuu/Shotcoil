이동 버튼이 없습니다.
총을 쏘면 그 반동으로 날아갑니다. 조준이 곧 이동입니다.

중력은 항상 당신을 끌어내립니다. 계속 쏴야 떠 있을 수 있고,
도망치려 쏜 총알이 적을 맞추고, 적을 맞추려 쏜 총알이
당신을 위험한 곳으로 밀어냅니다.


── 실행 ──────────────────────────────────────────────────────

  Shotcoil.exe 를 실행하면 됩니다.

  설치 과정이 없고, 별도 런타임이나 DLL이 필요 없습니다.
  Windows 10 / 11 64비트에서 동작합니다.

  최고 기록은 실행파일과 같은 폴더에 shotcoil.sav 로 저장됩니다.


── 조작 ──────────────────────────────────────────────────────

  마우스 이동      조준
  마우스 좌클릭    발사 (누르고 있으면 연사)
                   → 조준한 반대 방향으로 반동을 받아 날아갑니다

  1 / 2 / 3        웨이브 사이 강화 카드 선택 (클릭으로도 가능)
  R                강화 화면에서 카드 3장 새로고침 (횟수 제한)
  R                게임 오버 후 재시작
  T                타이틀에서 게임 방법 보기
  M                배경음악 끄기 / 켜기
  F11              전체화면 / 창 모드 전환
  ESC              타이틀로 / 종료


── 규칙 ──────────────────────────────────────────────────────

  · 탄약은 무제한입니다. 발사 간격이 비행을 제한합니다.
  · 바닥에 오래 머무르면 지면이 과열되어 피해를 입습니다.
    계속 공중에 떠 있어야 합니다.
  · 착지하지 않고 연속으로 처치하면 콤보 배수가 올라갑니다.
  · 웨이브를 넘길 때마다 강화 카드 3장 중 하나를 고릅니다.
  · 공격력을 영구히 올리는 방법이 세 가지 있습니다.
      - 웨이브 클리어
      - 주황색 공격력 상자 획득
      - 세 웨이브마다 주어지는 "도전" 달성
  · 드물게 "특수 증강"이 뜹니다. 판당 한 번만 얻을 수 있고,
    수치가 아니라 탄환의 규칙 자체를 바꿉니다. 총 8종.
  · 상자, 강화, 새로고침은 첫 실행 시 "게임 방법" 화면에서 설명합니다.
    (타이틀에서 T 키로 다시 볼 수 있습니다)
  · 5웨이브마다 보스가 등장합니다.
  · 무기는 총 11종. 적이 떨어뜨리는 아이템으로 교체됩니다.
